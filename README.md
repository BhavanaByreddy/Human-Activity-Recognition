## **🚶 Human Activity Recognition Using Machine Learning**

Human Activity Recognition (HAR) is a technology that identifies and classifies human activities such as walking, sitting, standing, laying, and climbing stairs using data collected from sensors. Smartphones and wearable devices use accelerometers and gyroscopes to capture movement data, which is then analyzed using machine learning algorithms. HAR helps in understanding human behavior and enables the development of intelligent applications in healthcare, fitness, security, and smart environment.

🏥 Healthcare Monitoring – Tracks patient activities and helps monitor health conditions remotely.

💪 Fitness Tracking – Measures physical activities such as walking, running, and exercise for fitness applications.

👴 Elderly Care – Detects falls and unusual movements, improving safety for older adults.

🔒 Security & Surveillance – Identifies suspicious or abnormal activities for enhanced security systems.

🤖 Smart Applications – Enables intelligent devices and wearable technology to provide personalized services.

## **✨ Features**
• Collects smartphone sensor data using accelerometer and gyroscope sensors.

• Performs data preprocessing and feature extraction for better accuracy.

• Uses Machine Learning algorithms for activity classification.

• Recognizes activities such as Walking, Sitting, Standing, and Laying.

• Supports real-time human activity monitoring.

• Provides accurate predictions and performance analysis.
